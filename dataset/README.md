# Dataset

Ground-truth datasets used by the offline replay simulator.

## Data acquisition

These are **synthetic ground-truth datasets** generated by
[`generate_dataset.py`](./generate_dataset.py) with a fixed random seed. They
model realistic indoor environmental dynamics (stable, occasional small
changes, one abrupt warm event with recovery) at **1 Hz**. They exist so the
simulator, tests and analysis run deterministically and repeatably **before a
physical ESP32 node is available**.

> Important: these are simulation inputs, **not** real sensor measurements.
> When a real node is deployed, replace the CSVs in `raw/` with ground truth
> collected from the device using `firmware` in "data-collection mode" (see
> `docs/experiment_protocol.md`). Never mix synthetic and real rows in one file.

## Format

Each file is CSV with a header and 1 row per second:

```csv
timestamp,temperature,humidity,pressure,light
0,24.1,45.2,1012.2,320.0
1,24.1,45.3,1012.2,321.2
```

| column | unit   | source channel                   |
|--------|--------|----------------------------------|
| timestamp | s   | time index, 0-based at 1 Hz      |
| temperature | degC | BME280 temperature            |
| humidity | %RH   | BME280 humidity                  |
| pressure | hPa   | BME280 pressure                  |
| light  | lux    | BH1750 (optional platform)   |

## Scenario files

| file | duration | events | description |
|------|----------|--------|-------------|
| `scenario_a_stable.csv` | 2 h | 0 | long run, essentially stable |
| `scenario_b_sudden.csv` | 30 min | 1 window | stable -> abrupt +5 degC -> recovery |
| `scenario_c_mixed.csv` | 2 h | 1 window | stable + small change + sudden + recovery + slow drift |

## "Ground truth events"

Ground-truth events are **not** stored in the raw CSV. They are derived at
analysis time by [`simulator/events.py`](../simulator/events.py) with the same
thresholds used for on-device detection, applied to the full-resolution signal.
Defining events in code from raw readings (rather than hand-labelling columns)
keeps ground truth and detected events comparable and prevents tuning the
ground truth to favour a strategy.

## Regeneration

```bash
python dataset/generate_dataset.py
```

The generator is seeded for reproducibility. Note that `generate_dataset.py`
documents the segment layout of each scenario, so the exact events embedded in
the signals are inspectable.

## Size note

Raw files are kept small (≈ 0.1–0.3 MB each) so no large binary artifacts are
committed. Larger collections made on real hardware should live outside the
repo or on a data server.
